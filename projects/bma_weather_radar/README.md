# 🌧️ BMA Weather Radar & Rain Tracker

โมดูลดึงข้อมูลภาพเรดาร์และรายงานสภาพฝน กทม. แบบ Real-time จากสำนักการระบายน้ำ กรุงเทพมหานคร

## ✨ ความสามารถหลัก (Features)
- **Dual Radar Stations**: ดึงภาพเรดาร์จากทั้งสถานีหนองแขม (NK) และสถานีหนองจอก (NC)
- **Official Rain Bulletin**: สกัดข้อความรายงานสภาพอากาศ อุณหภูมิ และความชื้นสัมพัทธ์
- **Automated Radar Animation**: บันทึกภาพ GIF/JPG สำหรับใช้งานใน Dashboard หรือแจ้งเตือน

## 🚀 วิธีใช้งาน (Usage)
```bash
# ใช้งานผ่านเมนู Interactive หรือรันดึงข้อมูลทันที
python3 run.py
```
