# Web Controller (ควบคุมผ่านมือถือ)

หน้าเว็บควบคุมโดรนแบบมาตรฐาน: วิดีโอสดเต็มจอ + จอยสติ๊กสัมผัส 2 ข้าง (โหมด 2: ซ้าย = คันเร่ง/หมุน, ขวา = เอน/เอียง)
+ ปุ่ม ARM / ขึ้นบิน (กดค้าง) / ลงจอด / ตีลังกา / ลอยนิ่ง / STOP + เลือกความแรงก้าน 30/60/100%
+ เมนูถ่ายภาพ, Headless, คาลิเบรตไจโร, สลับกล้อง และช่องกรอก URL เพื่อส่งภาพไปสตรีมต่อที่อื่น

## ติดตั้ง
```bash
source .venv/bin/activate
pip install -r requirements.txt        # flask, opencv-python, numpy
brew install ffmpeg                    # เฉพาะถ้าจะใช้ฟีเจอร์สตรีมต่อ
```

## รัน
```bash
python3 web_controller.py              # DRY RUN: ดูภาพได้ แต่ไม่ส่งคำสั่งไปที่โดรน (ค่าเริ่มต้น)
python3 web_controller.py --live       # ส่งคำสั่งจริง — ถอดใบพัดก่อนทดสอบครั้งแรกเสมอ
python3 web_controller.py --demo       # วิดีโอจำลอง ลองหน้าเว็บโดยไม่ต้องมีโดรน
```
โปรแกรมจะพิมพ์ลิงก์แบบ `http://<IP>:8080/?t=<รหัส>` ให้เปิดจากมือถือ
(รหัสสุ่มใหม่ทุกครั้ง ใช้ `--token xxx` ถ้าอยากตั้งเอง)

## ความปลอดภัยที่ใส่ไว้
- ค่าเริ่มต้นเป็น DRY RUN และความแรงก้านเริ่มที่ 30%
- ต้องมีรหัส `?t=` ทุกคำขอ; เครื่องที่ควบคุมได้มีเครื่องเดียว (เครื่องอื่นเป็นผู้ดู กด "ขอควบคุม" เพื่อสลับ)
- Deadman: ไม่ได้รับค่าก้านเกิน 0.4 วินาที → คืนก้านกลาง (ลอยนิ่ง)
- STOP สั่งได้จากทุกเครื่อง
- ขึ้นบิน/ลงจอดเป็นคำสั่งแบบสลับ (toggle) จึงมีการเช็กสถานะก่อนส่ง
  (ไม่ให้สั่ง "ลงจอด" ตอนที่ยังไม่ได้บิน เพราะจะกลายเป็นขึ้นบิน) และ DISARM ไม่ได้ขณะบิน
- `--failsafe-land 5` (ไม่บังคับ): ถ้าไม่มีเครื่องควบคุมเกิน 5 วินาทีขณะบิน จะสั่งลงจอด

## เครือข่าย (สำคัญ)
- Mac ต้องต่อ WiFi ของโดรน เพื่อส่ง UDP และดึง RTSP
- มือถือต้องเข้าถึง IP ของ Mac ได้: ต่อ WiFi โดรนเดียวกัน (ถ้าโดรนรับหลายเครื่อง — ยังไม่ได้ทดสอบ)
  หรือให้ Mac มีอีกช่องทาง (สาย LAN / USB tethering) แล้วให้มือถืออยู่วง LAN นั้น
- การสตรีมต่อออกอินเทอร์เน็ต (YouTube ฯลฯ) ต้องให้ Mac ออกเน็ตได้ผ่านช่องทางที่สอง
  ถ้ามีแค่ WiFi โดรน จะไม่มีอินเทอร์เน็ต
- ถ้าวง LAN อีกวงเป็น 192.168.1.x จะชนกับ IP โดรน (192.168.1.1)

## ยังไม่มี (ตั้งใจตัดออกก่อน)
HUD ตัวเลข telemetry (โดรนไม่ส่งมา), อัดวิดีโอลงเครื่อง,
ระบบตรึงตำแหน่งด้วยภาพ (ยังอยู่ใน drone_controller.py)
