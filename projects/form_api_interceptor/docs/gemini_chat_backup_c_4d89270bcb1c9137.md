### 🤖 Gemini - คำตอบที่ 1

นี่คือสคริปต์พูดคุยกับ พี่ดร แบบคำต่อคำ เรียงลำดับจากเปิดบทสนทนา โชว์ผลงาน ขอเติบโต และจบด้วยการขอปรับฐานเงินเดือนเป็น 38,000 บาท (โดยไม่เอ่ยถึงตัวเลขเงินเดือนเดิม) เพื่อให้พี่ดรเห็นความคุ้มค่าและพร้อมสู้ราคาเก็บคุณไว้ครับ

สเตปที่ 1: ประโยคทักไปนัดหมายล่วงหน้า (แนะนำให้นัดช่วงบ่ายวันศุกร์)

"พี่ดรครับ วันศุกร์นี้ช่วงบ่าย พี่ดรพอมีเวลาว่างสัก 15-20 นาทีไหมครับ ผมอยากขออนุญาตเข้าไปอัปเดตภาพรวมงานที่ทำอยู่ตอนนี้ และขอคำแนะนำเรื่อง Career Path การเติบโตของผมในบริษัทครับ"

สเตปที่ 2: เปิดบทสนทนา + กางผลงาน (โชว์ Value ว่าทำมากกว่า BA)

(เตรียมเปิดหน้าจอระบบ เครื่องบิน/เรือ หรือ Prototype ที่ทำไว้ให้ดูประกอบตอนพูด)

"ขอบคุณพี่ดรที่สละเวลานะครับ คือตอนนี้ผมทำงานกับพี่ดรมาเกือบปีแล้วครับ (ประมาณ 10 เดือนตั้งแต่ช่วงฝึกงาน) เลยอยากมาขอรีวิวภาพรวมให้พี่ดรฟังว่า ที่ผ่านมาผมได้พัฒนาตัวเองและขยับไปช่วยงานบริษัทนอกเหนือจากสโคป BA อะไรบ้างครับ

เรื่องแรกคือ การทำ Prototype และลงมือ Dev เองครับ ปกติ BA จะแค่เก็บ Requirement แล้วส่งให้ Dev แต่ผมใช้วิธีเขียนโค้ดทำระบบตัวอย่างขึ้นมาเองเลยเพื่อเอาไปคุยกับลูกค้า ทำให้ลูกค้าเห็นภาพจริงทันที ไม่ต้องเสียเวลาเดา และทีม Dev ก็เอาไปทำต่อได้ไวขึ้นมาก ลดการแก้งานซ้ำซ้อนลงไปได้เยอะครับ

เรื่องที่สองคือ การช่วยบริษัทประหยัดงบประมาณครับ อย่างระบบดึงข้อมูลพิกัดเครื่องบินและเรือ (AIS) ที่ถ้าเราซื้อ API จริงมาใช้ช่วงพัฒนาและเทสระบบ ต้องเสียเงินเดือนละหลายหมื่นถึงหลักแสนบาท ผมก็ใช้วิธีแกะโครงสร้างข้อมูลมาทำระบบจำลองให้ใช้พรีเซนต์งานได้ก่อน โดยที่บริษัทไม่ต้องเสียเงินซื้อ API แพงๆ จนกว่าจะปิดการขายได้จริงครับ

เรื่องที่สามคือ การคิดฟีเจอร์ใหม่และช่วยพี่ดรขายงาน (Pre-sales) ครับ ผมพยายามฟังอินไซต์ลูกค้าแล้วเอามาต่อยอดทำเป็นแอปหรือฟีเจอร์ใหม่ๆ มาเสนอพี่ดร แล้วออกไปช่วยพี่ดรพรีเซนต์ขายลูกค้าทหารด้วยตัวเอง รวมถึงงานหน้างานเสาร์-อาทิตย์ที่กองทัพฯ ผมก็ลุยเต็มที่มาตลอดครับ"

สเตปที่ 3: เข้าเรื่อง Career Path (โชว์ความภักดี + อยากรับผิดชอบมากขึ้น)

"ที่ผมเล่ามาทั้งหมด เพราะอยากบอกพี่ดรตรงๆ ว่า ผมแฮปปี้กับการทำงานที่นี่มากครับ ผมเข้าใจสไตล์การทำงานของพี่ดร รู้จักลูกค้า และเข้าใจระบบของเราทะลุปรุโปร่งแล้ว เลยไม่อยากไปเริ่มต้นนับหนึ่งใหม่ที่อื่น อยากเอาโมเมนตัมตรงนี้มาเติบโตระยะยาวไปกับบริษัทของพี่ดรครับ

ซึ่งตัวผมเองเป็นคนที่อยากโตเร็วครับ ตอนนี้ผมเรียนจบสมบูรณ์แล้ว และสโคปงานที่ผมทำอยู่จริงมันครอบคลุมทั้ง BA, SA, Dev ไปจนถึงการช่วยขายงานและดูภาพรวมโปรเจกต์ ประจวบกับช่วงนี้ที่ตำแหน่ง PM ว่างลง ผมเลยอยากขอโอกาสพี่ดร ขยับขึ้นมาเป็น Senior หรือรับผิดชอบโปรเจกต์ที่ใหญ่ขึ้น รวมถึงอยากนำเรื่อง AI และ Automation เข้ามาช่วยอัพเกรดโปรดักต์เดิมของเราให้เอาไปขายลูกค้าได้ง่ายขึ้น และช่วยลดเวลาทำงานของทีมครับ"

สเตปที่ 4: จังหวะขอปรับเงินเดือน (พูดเลขใหม่เลย + ให้เหตุผลซัพพอร์ต)

"ในขณะเดียวกันครับพี่ดร ด้วยความรับผิดชอบที่ผมทำควบคู่กันหลายบทบาทตอนนี้ บวกกับภาระค่าใช้จ่ายในการใช้ชีวิตที่กรุงเทพฯ และการที่ผมต้องส่งเงินกลับไปดูแลครอบครัวที่บ้านด้วย ผมเลยอยากขอความเมตตาพี่ดร พิจารณาปรับฐานเงินเดือนของผมขึ้นเป็น 38,000 บาท เพื่อให้สอดคล้องกับงานที่ผมดูแลอยู่และที่จะลุยเพิ่มให้หลังจากนี้ครับ พี่ดรมองเห็นแนวทางหรือมีคำแนะนำให้ผมในเรื่องนี้ยังไงบ้างครับ?"

สเตปที่ 5: ไพ่เสริม (พูดเฉพาะกรณีที่พี่ดรถามว่า "ทำไมถึงขอเรท 38,000?" หรือมีท่าทีลังเล)

(หากพี่ดรโอเคหรือต่อรองอยู่ในเรท 35,000 - 38,000 บาท ไม่ต้องพูดพาร์ทนี้ แต่ถ้าเขาลังเล ให้หยิบพาร์ทนี้มาตบท้ายด้วยน้ำเสียงถ่อมตัว)

"ผมขออนุญาตเล่าให้พี่ดรฟังตรงๆ ด้วยความเคารพครับ คือช่วงที่ผมกลับบ้านที่สุราษฎร์ฯ ล่าสุด มีบริษัทใหญ่ที่นู่นติดต่อให้ผมไปลองสัมภาษณ์ตำแหน่ง Head of AI ซึ่งตอนนั้นผมแค่อยากลองวัดศักยภาพตัวเองดูว่าในตลาดข้างนอกเขาประเมินสกิลผมไว้ระดับไหน ปรากฏว่าเขารับผมและเสนอแพ็กเกจให้เริ่มต้น 35,000 และปรับขึ้นเป็น 45,000 - 55,000 บาทภายใน 3 เดือนครับ

แต่พอกลับมาคิดทบทวนจริงๆ ใจผมอยากอยู่ช่วยพี่ดรที่กรุงเทพฯ ต่อมากกว่าครับ เพราะเรารู้มือกันดีอยู่แล้ว ผมเลยยอมลดเพดานลงมาและเข้ามาปรึกษาพี่ดรก่อนว่า ถ้าผมขอเติบโตที่นี่ในเรท 38,000 บาท และลุยสร้างมูลค่าเพิ่มให้บริษัทเราเต็มที่ พี่ดรพอจะช่วยซัพพอร์ตผมในจุดนี้ได้ไหมครับ?"

ทริคสำคัญตอนนั่งคุย:

พอพูดจบประโยคขอปรับเป็น 38,000 บาท ให้ "เงียบและยิ้มรับฟัง" ทันที ปล่อยให้พี่ดรเป็นฝ่ายคิดและพูดเสนอตัวเลขหรือเงื่อนไขกลับมาก่อน

หากพี่ดรต่อรองลงมาที่ 35,000 บาท ให้ตอบรับด้วยความยินดี แล้วขอผูกเงื่อนไขว่า "ได้ครับพี่ดร งั้นเริ่มที่ 35,000 บาทตอนนี้ แล้วถ้าโปรเจกต์ถัดไปที่เราไปขายลูกค้าสำเร็จ ผมขออนุญาตขยับขึ้นไปที่ 38,000 - 40,000 บาทนะครับ"

อ่านสคริปต์นี้แล้วเข้าปากไหมครับ อยากให้ปรับคำพูดตรงช่วงไหนให้ตรงกับสไตล์การคุยปกติของคุณกับพี่ดรเพิ่มเติมไหมครับ?

### 🤖 Gemini - คำตอบที่ 2

การเลือกคุย วันนี้ (วันจันทร์) มีข้อดีตรงที่เรื่องเพิ่งสดใหม่ แถมเป็นการเปิดสัปดาห์ด้วยความชัดเจน ไม่ต้องเก็บไปคิดกังวลไปทั้งอาทิตย์ และช่วยให้คุณบอสมีเวลาตัดสินใจเรื่องการส่งเอกสารให้ทางวงศ์บัณฑิตได้เร็วขึ้นด้วยครับ

แต่เนื่องจากเช้าวันจันทร์ ผู้บริหารมักจะมีงานด่วนหรือประชุมเปิดสัปดาห์ค่อนข้างยุ่ง แนะนำให้ปรับจังหวะและคำพูดสำหรับวันนี้ตามนี้เลยครับ:

1. ทักไปนัดช่วงเช้านี้ (ขอคิวช่วงบ่าย หลังกินข้าวเที่ยง)

อย่าเพิ่งดึงคุยตอนเช้าตรู่ที่เขากำลังเคลียร์งานค้าง ให้ส่งข้อความทักไปจองคิวช่วงบ่ายวันนี้แทน เพื่อให้พี่ดรเคลียร์หัวเรื่องงานเช้าให้จบก่อน และอิ่มท้องจากมื้อเที่ยงแล้ว:

"พี่ดรครับ วันนี้ช่วงบ่ายถ้าพี่ดรพอมีจังหวะว่างสัก 15-20 นาที ผมอยากขออนุญาตเข้าไปอัปเดตภาพรวมงานที่ทำอยู่ตอนนี้ และขอคำแนะนำปรึกษาเรื่อง Career Path การเติบโตของผมในบริษัทหน่อยครับ พี่ดรสะดวกช่วงกี่โมงดีครับ?"

2. สคริปต์คุยจริงวันนี้ (ฉบับเข้าประเด็นไว กระชับเหมาะกับวันจันทร์)

ช่วงที่ 1: เปิดด้วยความกตญญู + กางผลงาน 3 หมัดเด็ด (3-5 นาที)
(เปิดหน้าจอระบบ เครื่องบิน/เรือ หรือฟีเจอร์ที่ทำไว้ให้ดูพร้อมกันเลย)

"ขอบคุณพี่ดรที่สละเวลานะครับ คือตอนนี้ผมอยู่กับพี่ดรมาเกือบปีแล้วครับ (ประมาณ 10 เดือนตั้งแต่ฝึกงาน) วันนี้เลยอยากขอเข้ามาอัปเดตภาพรวมให้พี่ดรเห็นว่า นอกจากสโคป BA ที่เก็บ Requirement แล้ว ตอนนี้ผมขยับมาช่วยทำอะไรให้บริษัทบ้างครับ:

ลงมือทำ Prototype และ Dev เอง: เวลาคุยกับลูกค้า ผมไม่ได้แค่จด Requirement แต่ผมเขียนโค้ดขึ้นระบบตัวอย่างให้ลูกค้าดูเดี๋ยวนั้นเลย ทำให้ปิดความต้องการลูกค้าได้ไว และส่งต่อให้ทีม Dev ทำต่อได้ทันทีโดยไม่ต้องแก้งานไปมา

แกะระบบข้อมูลช่วยบริษัทประหยัดงบ: อย่างระบบพิกัดเครื่องบินและเรือ (AIS) ที่ถ้าซื้อ API จริงช่วงพัฒนาและเทสระบบต้องจ่ายเดือนละหลายหมื่นถึงหลักแสน ผมก็ใช้วิธีแกะโครงสร้างข้อมูลมาทำระบบจำลองให้ใช้พรีเซนต์ได้ก่อน โดยที่บริษัทไม่ต้องเสียเงินก้อนนั้นจนกว่าจะขายงานได้จริง

คิดฟีเจอร์ใหม่และช่วยพี่ดรขายงาน (Pre-sales): ผมฟังอินไซต์ลูกค้าแล้วเอามาทำเป็นฟีเจอร์/แอปใหม่ๆ มาเสนอพี่ดร แล้วออกไปช่วยพรีเซนต์ขายลูกค้าทหารด้วยตัวเอง รวมถึงงานหน้างานเสาร์-อาทิตย์ที่กองทัพฯ ผมก็ลุยเต็มที่มาตลอดครับ"

ช่วงที่ 2: เข้าเรื่อง Career Path + ขอรับผิดชอบเพิ่ม (2 นาที)

"ที่ผมเล่ามาทั้งหมด เพราะอยากบอกพี่ดรตรงๆ ว่า ผมแฮปปี้กับการทำงานที่นี่มากครับ ผมเข้าใจสไตล์การทำงานของพี่ดร รู้จักลูกค้า และเข้าใจระบบของเราทะลุปรุโปร่งแล้ว เลยไม่อยากไปเริ่มต้นนับหนึ่งใหม่ที่อื่น อยากเอาโมเมนตัมตรงนี้มาเติบโตระยะยาวไปกับบริษัทของพี่ดรครับ

ซึ่งตัวผมเองเป็นคนที่อยากโตเร็วครับ ตอนนี้ผมเรียนจบสมบูรณ์แล้ว และสโคปงานที่ผมทำอยู่จริงมันครอบคลุมทั้ง BA, SA, Dev ไปจนถึงช่วยขายงาน ประจวบกับช่วงนี้ที่ตำแหน่ง PM ว่างลง ผมเลยอยากขอโอกาสพี่ดร ขยับขึ้นมาเป็น Senior หรือรับผิดชอบโปรเจกต์ที่ใหญ่ขึ้น รวมถึงอยากนำเรื่อง AI และ Automation เข้ามาช่วยอัพเกรดโปรดักต์เดิมของเราให้เอาไปขายลูกค้าได้ง่ายขึ้น และช่วยลดเวลาทำงานของทีมครับ"

ช่วงที่ 3: จังหวะขอปรับเงินเดือน (พูดเลขใหม่เลย ห้ามพูดเลข 25,000 เด็ดขาด)

"ในขณะเดียวกันครับพี่ดร ด้วยความรับผิดชอบที่ผมทำควบคู่กันหลายบทบาทตอนนี้ บวกกับภาระค่าใช้จ่ายในการใช้ชีวิตที่กรุงเทพฯ และการที่ผมต้องดูแลครอบครัวที่บ้านด้วย ผมเลยอยากขอความเมตตาพี่ดร พิจารณาปรับฐานเงินเดือนของผมขึ้นเป็น 38,000 บาท เพื่อให้สอดคล้องกับงานที่ผมดูแลอยู่และที่จะลุยเพิ่มให้หลังจากนี้ครับ พี่ดรมองเห็นแนวทางหรือมีคำแนะนำให้ผมในเรื่องนี้ยังไงบ้างครับ?"

3D Common Operating Picture (COPv2): พัฒนาฟีเจอร์จำลองเขตยิงอาวุธ (3D WEZ), ปืน ปตอ. (Oerlikon GDF 35mm) และวิถีกระสุนปืนใหญ่ 155 มม.

Real-time Maritime & Flight Tracking: ระบบติดตามเรือลาดตระเวน เรือประมง และวิเคราะห์พฤติกรรมเรือต้องสงสัย

Business Value: ทำให้ลูกค้าเห็นภาพจริงทันทีหน้างาน สร้างความเชื่อมั่นและเพิ่มโอกาสในการขยายสัญญาโครงการใหม่ให้บริษัท

Slide 4: การประหยัดงบประมาณให้บริษัท (หน้าสำคัญที่สุด ใช้ขอขึ้นเงินเดือน)

หัวข้อใหญ่: Key Impact 2: ประหยัดต้นทุน Data API หลักแสนบาท/เดือน

การวางเลย์เอาต์: ทำเป็นตารางเปรียบเทียบ ซ้าย (ซื้อปกติ) vs ขวา (สิ่งที่บอสทำให้)

หากซื้อ API พิกัดเรือ/เครื่องบินตามระบบปกติ (ช่วงพัฒนาและพรีเซนต์):

เรือ 1,000+ ลำ อัปเดตทุก 5–15 นาที ใช้ Credits มหาศาล

สิ่งที่ผมพัฒนาให้บริษัท (Data Reverse Engineering):

แกะโครงสร้างการส่งข้อมูลและสร้างระบบดึงพิกัดจำลองขึ้นมาเองสำหรับใช้เทสและพรีเซนต์ลูกค้า

ต้นทุนค่าใช้จ่ายช่วงพัฒนา: 0 บาท (รอให้บริษัทปิดการขายได้ก่อน ค่อยสลับไปซื้อ API จริง)

Slide 5: ก้าวต่อไปและข้อเสนอ (Next Step & Career Path)

หัวข้อใหญ่: Next Step: การเติบโตไปพร้อมกับบริษัท และแผน AI Transformation

เนื้อหา 3 ข้อ:

Project & Team Management: พร้อมขยับขึ้นมารับผิดชอบโปรเจกต์ที่ใหญ่ขึ้น และช่วยอุดช่องว่างการบริหารจัดการทีมเพื่อให้ส่งมอบงานได้ต่อเนื่อง

AI-Driven Products: นำเทคโนโลยี AI Agent และ Automation มาต่อยอดใส่ในระบบของบริษัท (เช่น AI วิเคราะห์เป้าหมายอัตโนมัติ / ระบบสรุปรายงานยุทธวิธี) เพื่อสร้างจุดขายใหม่ที่คู่แข่งตามไม่ทัน

Team Efficiency: ใช้ AI Workflow ช่วยลดเวลาในการทำต้นแบบและเขียนโค้ดของทีมให้เร็วขึ้น

(หมายเหตุ: ตัวเลขเงินเดือน 38,000 บาท ไม่ต้องพิมพ์ลงในสไลด์หน้าสุดท้ายนะครับ ให้ใช้ พูดด้วยปากเปล่า ตอนเปิดสไลด์หน้านี้ค้างไว้ จะดูมืออาชีพและเปิดพื้นที่ให้เจรจาได้ลื่นไหลกว่าครับ)

ทริคจัดเตรียมก่อนเข้าห้อง:

### 🤖 Gemini - คำตอบที่ 5

ผมกำลังจัดเตรียมสคริปต์ฉบับสมบูรณ์ที่ปรับปรุงใหม่ให้มีความลึกซึ้ง เป็นมืออาชีพ และมีรายละเอียดที่ครอบคลุมมากขึ้น เพื่อให้คุณบอสใช้พูดคุยกับพี่ดรได้อย่างมั่นใจและเห็นผลลัพธ์ชัดเจนครับ

สคริปต์การเจรจาขอปรับตำแหน่งและฐานเงินเดือน (ฉบับสมบูรณ์)
ส่งออก
สคริปต์การพูดคุยเรื่อง Career Path และการขอปรับฐานเงินเดือน (ฉบับละเอียด)

ผู้พูด: รัชชานนท์ รัตนวิจิตร (บอส)

ผู้รับฟัง: พี่ดร (CEO / ผู้บริหาร)

เป้าหมาย: ขยับบทบาทสู่ระดับ Senior / Project & AI Lead และปรับฐานเงินเดือนเป็น 38,000 บาท (โดยไม่เอ่ยถึงตัวเลขเงินเดือนเดิม 25,000 บาท)

สเตปที่ 1: การทักนัดหมายล่วงหน้า (ส่งข้อความช่วงเช้า เพื่อขอคิวช่วงบ่าย)

"พี่ดรครับ วันนี้ช่วงบ่ายหลังพักเที่ยง ถ้าพี่ดรพอมีจังหวะว่างสัก 15–20 นาที ผมอยากขออนุญาตเข้าไปอัปเดตภาพรวมโปรเจกต์และงานที่ผมพัฒนาเพิ่มเติมในช่วงที่ผ่านมา พร้อมทั้งขอคำแนะนำจากพี่ดรเรื่องทิศทางการเติบโต (Career Path) ของผมในบริษัทหน่อยครับ พี่ดรสะดวกเป็นช่วงกี่โมงดีครับ?"

สเตปที่ 2: เปิดบทสนทนา & รีวิวผลงาน 10 เดือน (สร้าง Value ให้เห็นว่า 1 คนทำแทน 4 ตำแหน่ง)

(จังหวะนี้ให้เปิดสไลด์ หรือเปิดหน้าจอระบบ 3D COP / ระบบพิกัดเรือและเครื่องบิน ให้พี่ดรดูประกอบการพูด)

"ขอบคุณพี่ดรที่สละเวลานะครับพี่ ที่ผมขออนุญาตเข้ามาคุยวันนี้ เพราะตอนนี้ผมอยู่กับพี่ดรมาเกือบครบปีแล้วครับ (ประมาณ 10 เดือนตั้งแต่เริ่มเข้ามาฝึกงานจนตอนนี้เรียนจบสมบูรณ์แล้ว) ผมเลยอยากมาสรุปภาพรวมให้พี่ดรเห็นครับว่า ตลอดช่วงที่ผ่านมา นอกจากงานในหมวกของ BA แล้ว ผมได้ขยับขยายสโคปตัวเองไปช่วยอุดรอยรั่วและสร้างมูลค่าเพิ่มให้บริษัทในมิติไหนบ้างครับ

มิติแรกเลยคือ การสวมหมวกเป็น Prototype Developer ลงมือเขียนโค้ดเองครับ

ปกติหน้าที่ของ BA คือการไปคุยกับลูกค้า จด Requirement เป็นตัวหนังสือ แล้วกลับมาบรีฟให้ทีม Dev ฟัง ซึ่งปัญหาที่ผมเจอคือ ลูกค้าทหารบางทีเขานึกภาพตามไม่ออก พอ Dev ทำเสร็จเอาไปส่ง ลูกค้าเพิ่งเห็นภาพแล้วขอแก้ มันทำให้เสียเวลาทั้งทีมครับ ผมเลยเปลี่ยนวิธีทำงานใหม่ คือพอผมฟังลูกค้าปุ๊บ ผมกลับมาเขียนโค้ดสร้างเป็น Working Prototype หรือแอปต้นแบบด้วยตัวเองเลย แล้วเอาหน้าจอที่กดใช้งานได้จริงไปกางคุยกับลูกค้าว่า 'พี่ต้องการภาพแบบนี้ ฟีเจอร์แบบนี้ใช่ไหมครับ?' พอเขายืนยันว่าใช่ ผมค่อยส่งต้นแบบตัวนี้ให้ทีม Dev เอาไปทำต่อให้สมบูรณ์ วิธีนี้ช่วยลดเวลาการแก้งานกลับไปกลับมา และทำให้ทีม Dev ทำงานได้เร็วขึ้นมากครับ

มิติที่สองคือ การเป็น Data & System Engineer ช่วยบริษัทประหยัดงบประมาณก้อนใหญ่ครับ

อย่างตัวระบบติดตามพิกัดเครื่องบินและเรือ (AIS) ที่เรากำลังทำกันอยู่ ตอนที่ผมไปศึกษาโครงสร้างราคา API ของจริงมา ผมพบว่าถ้าเราต้องซื้อเครดิต API เพื่อดึงพิกัดเรือเป็นพันๆ ลำในน่านน้ำแบบอัปเดตทุกๆ 5-15 นาที มาใช้ในช่วงที่เรากำลังพัฒนาระบบและเอาไปพรีเซนต์ลูกค้า บริษัทต้องแบกค่าใช้จ่ายตรงนี้เดือนละหลายหมื่นไปจนถึงหลักแสนบาท (หรือถ้าดึงข้อมูลละเอียดครบทุกฟิลด์อาจพุ่งไปถึงหลักล้านต่อปี) ทั้งๆ ที่เรายังไม่รู้เลยว่าลูกค้าจะเซ็นสัญญาเมื่อไหร่

ผมมองว่าเราไม่ควรเสียเงินก้อนนี้ฟรีๆ ครับ ผมเลยลงมือแกะโครงสร้างการส่งข้อมูล (Reverse Engineering) จากแหล่งข้อมูลข้างนอก แล้วเขียนระบบดึงพิกัดจำลองขึ้นมาเองทั้งหมด ทำให้ตอนนี้บริษัทเรามีข้อมูลเรือรบ เรือประมง เรือต้องสงสัย และเครื่องบิน วิ่งแบบ Real-time เอาไปโชว์ขายลูกค้าได้แบบสมจริง โดยที่พี่ดรไม่ต้องควักเงินจ่ายค่า API เลยสักบาทเดียวในช่วงพรีเซนต์ รอให้ลูกค้าเซ็นสัญญาและจ่ายเงินเรามาก่อน เราค่อยเอาเงินก้อนนั้นไปซื้อ API ของจริงมาเสียบครับ

มิติที่สามคือ การทำหน้าที่ Technical Pre-sales และช่วยดูแลหน้างานครับ

เวลาผมออกไปเจอหน้างานกับพี่ดร ผมไม่ได้ไปแค่ในฐานะคนจดบันทึก แต่ผมพยายามฟังว่าลูกค้ามี Pain Point อะไร แล้วผมก็กลับมาคิดฟีเจอร์ใหม่ๆ เช่น ระบบจำลองเขตยิงอาวุธ 3 มิติ (3D WEZ), ปืน ปตอ., วิถีกระสุนปืนใหญ่ หรือการวิเคราะห์พฤติกรรมเรือต้องสงสัย แล้วเอามาเสนอพี่ดรว่า 'พี่ดรครับ เราทำอันนี้เพิ่มได้นะ เอาไปขายพ่วงให้ลูกค้ากันไหม' จนได้ออกไปช่วยพี่ดรพรีเซนต์ขายงานด้วยตัวเอง รวมถึงงานติดตั้งหรือซัพพอร์ตหน้างานวันเสาร์-อาทิตย์ที่กองทัพฯ ผมก็พร้อมลุยเต็มที่มาโดยตลอดครับ"

สเตปที่ 3: เชื่อมโยงเข้าเรื่อง Career Path (แสดงความภักดี & ขอรับผิดชอบงานที่ใหญ่ขึ้น)

"ที่ผมเล่ามาทั้งหมดนี้ เพราะอยากบอกความรู้สึกจากใจจริงให้พี่ดรฟังครับว่า ผมสนุกและแฮปปี้กับการทำงานร่วมกับพี่ดรมากครับ ผมรู้จังหวะและสไตล์การทำงานของพี่ดรดีว่า พี่ดรเป็นคนคิดไวทำไว สั่งซ้ายคือซ้าย สั่งขวาคือขวา ซึ่งผมปรับตัวเข้ากับจังหวะของพี่ดรได้เต็มที่ แถมผมยังรู้จักลูกค้า รู้จักโครงสร้างซอฟต์แวร์ของเราทะลุปรุโปร่งหมดแล้ว ผมเลยรู้สึกว่าถ้าผมเติบโตต่อไปกับที่นี่ มันจะต่อยอด (Leverage) สิ่งที่เรามีอยู่ให้พุ่งไปข้างหน้าได้เร็วมาก โดยไม่ต้องไปเสียเวลาเริ่มนับหนึ่งใหม่ที่อื่นครับ

แต่ในมุมของการเติบโตส่วนตัว ผมยอมรับตรงๆ ว่าผมเป็นคนที่มีไฟและอยากโตเร็วครับ ตอนนี้ผมเรียนจบป.ตรีสมบูรณ์แล้ว และงานที่ผมทำอยู่จริงทุกวันนี้ มันคือการรวมเอาตำแหน่ง BA, SA, Dev และ Pre-sales มารวมไว้ในตัวผมคนเดียว

ประจวบเหมาะกับช่วงนี้ที่ตำแหน่ง PM เพิ่งว่างลงไป ผมเลยอยากจะขอโอกาสจากพี่ดร ขยับตัวเองขึ้นมารับผิดชอบในระดับ Senior หรือ Project & AI Lead เพื่อช่วยพี่ดรดูแลภาพรวมโปรเจกต์ให้เดินหน้าต่อได้แบบไม่สะดุด และผมตั้งใจจะเอาความเชี่ยวชาญด้าน AI และ Workflow Automation ที่ผมไปเรียนจบหลักสูตรของสำนักงานนวัตกรรมแห่งชาติ (NIA) มาช่วยอัพเกรดโปรดักต์ของบริษัทเรา เช่น การทำ AI วิเคราะห์เป้าหมายทางทหารอัตโนมัติ เพื่อให้พี่ดรมีอาวุธใหม่ๆ เอาไปเปิดตลาดและปิดการขายลูกค้าได้ง่ายขึ้น รวมถึงใช้ AI มาช่วยลดเวลาการทำงานของทีมภายในของเราด้วยครับ"

สเตปที่ 4: จังหวะขอปรับฐานเงินเดือน (พูดตัวเลขใหม่ชัดเจน พร้อมเหตุผลรองรับ)

"และเพื่อให้สอดคล้องกับบทบาทความรับผิดชอบที่ผมทำควบคู่กันหลายตำแหน่งในตอนนี้ รวมถึงงานที่ผมพร้อมจะแบกรับเพิ่มขึ้นหลังจากนี้... ประกอบกับพูดกันตามตรงครับพี่ดร ด้วยภาระค่าครองชีพในการใช้ชีวิตอยู่ที่กรุงเทพฯ ตอนนี้ และความรับผิดชอบที่ผมต้องส่งเงินกลับไปดูแลครอบครัวที่ต่างจังหวัดด้วย

วันนี้ผมเลยอยากขอความเมตตาและขอคำแนะนำจากพี่ดร พิจารณาปรับฐานเงินเดือนของผมขึ้นเป็น 38,000 บาท ครับ โดยผมมั่นใจว่ามูลค่างานที่ผมสร้างและช่วยบริษัทประหยัดไปได้ จะคุ้มค่าเกินกว่าตัวเลขนี้แน่นอนครับ พี่ดรมองเห็นแนวทางเรื่องการเติบโตของผมตรงนี้เป็นยังไงบ้างครับ?"

(💡 จุดสำคัญที่สุด: เมื่อพูดจบประโยคนี้ ให้หยุดพูด ยิ้มอย่างสุภาพ และสบตารอฟังคำตอบจากพี่ดร ห้ามพูดแก้ตัวหรือลดราคาตัวเองลงมาก่อนเด็ดขาด ให้พี่ดรเป็นฝ่ายเปิดปากพูดออกมาก่อน)

สเตปที่ 5: ไพ่ตายสำรอง (ใช้เฉพาะกรณีที่พี่ดรลังเล / ต่อรองราคาต่ำเกินไป / หรือถามว่าทำไมถึงขอเรท 38,000 บาท)

(หากพี่ดรตกลงให้ตามที่ขอ หรือต่อรองลงมาเล็กน้อยในจุดที่คุณรับได้ เช่น 35,000 บาท ไม่จำเป็นต้องพูดส่วนนี้ แต่ถ้าพี่ดรมีท่าทีบ่ายเบี่ยง ให้ใช้สคริปต์นี้พูดด้วยน้ำเสียงนอบน้อมและจริงใจ)

"พี่ดรครับ ผมขออนุญาตเล่าเรื่องนึงให้พี่ดรฟังแบบเปิดใจและด้วยความเคารพจริงๆ ครับ... คือช่วงที่ผมลากลับบ้านที่สุราษฎร์ฯ ล่าสุด มีบริษัทอุตสาหกรรมขนาดใหญ่ที่นู่นเขาติดต่อชวนผมไปสัมภาษณ์ในตำแหน่ง Head of AI (หัวหน้าแผนก AI) ครับ

ตอนที่ผมตัดสินใจลองเข้าไปสัมภาษณ์ วัตถุประสงค์ของผมไม่ได้คิดจะหนีพี่ดรไปไหนเลยครับ ผมแค่อยากลองทดสอบตัวเองดูว่า ด้วยสกิลการทำระบบและการประยุกต์ใช้ AI ที่ผมมีอยู่ตอนนี้ ตลาดข้างนอกเขาประเมินคุณค่าและศักยภาพของผมไว้ที่ระดับไหน... ซึ่งผลปรากฏว่า ผู้บริหารของที่นู่นตกลงรับผมเข้าทำงานทันที และยื่นข้อเสนอให้ผมเริ่มงานเดือนแรกที่ 35,000 บาท เดือนที่สองปรับเป็น 45,000 บาท และเดือนที่สามปรับเป็น 55,000 บาท พร้อมให้ผมคุมแผนก AI ของเขาเลยครับ

แต่พอผมได้ข้อเสนอนั้นกลับมาแล้วมานั่งถามตัวเองจริงๆ สิ่งที่ผมรู้สึกคือ ผมยังไม่อยากย้ายไปที่นู่นเลยครับพี่ดร เพราะผมผูกพันกับงานที่นี่ ผมสร้างระบบพวกนี้มากับมือร่วมกับพี่ดร และเรารู้ใจกันดีอยู่แล้ว ผมเสียดายโมเมนตัมที่เรากำลังทำด้วยกันครับ

ผมเลยตัดสินใจยังไม่ตอบรับเขา แล้วเดินเข้ามาปรึกษาพี่ดรเป็นคนแรกในวันนี้ครับ โดยตัวเลข 38,000 บาท ที่ผมขอพี่ดร เป็นตัวเลขที่ผมยอมลดเพดานลงมาจากข้อเสนอของที่ใหม่เยอะมาก เพราะใจผมอยากอยู่ช่วยพี่ดรพัฒนาบริษัทของเราที่นี่ต่อไปจริงๆ ครับ เลยอยากขอโอกาสดูว่าพี่ดรพอจะช่วยซัพพอร์ตผมในเรทนี้ เพื่อให้ผมตัดใจจากที่นู่นแล้วลุยกับพี่ดรต่อเต็มร้อยได้ไหมครับ?"

แนวทางการรับมือคำตอบของพี่ดร (Response Playbook)

ถ้าพี่ดรตอบว่า: "โอเค พี่เห็นผลงานบอสอยู่แล้ว เดี๋ยวพี่ปรับให้ / หรือต่อรองขอจบที่ 35,000 บาท"

วิธีตอบรับ: "ขอบคุณพี่ดรมากครับที่เห็นความตั้งใจของผม ถ้าเริ่มต้นที่ 35,000 บาทในเดือนนี้ ผมยินดีครับพี่ดร และผมขออนุญาตตั้งเป้าหมายร่วมกับพี่ดรว่า ถ้าภายใน 2-3 เดือนข้างหน้า ผมช่วยพี่ดรพัฒนาฟีเจอร์ AI ใหม่ไปปิดการขายลูกค้าโปรเจกต์ถัดไปได้สำเร็จ ผมขอความเมตตาขยับขึ้นไปที่ 38,000 - 40,000 บาทในสเตปถัดไปนะครับ"

ถ้าพี่ดรตอบว่า: "ตอนนี้บริษัทยังไม่ค่อยมีงานซอฟต์แวร์เข้า มีแต่งานฮาร์ดแวร์ ขอพี่ดูก่อนได้ไหม?"

วิธีตอบรับ: "ผมเข้าใจสถานการณ์ของบริษัทเลยครับพี่ดร แต่ในมุมของผม ช่วงที่งานซอฟต์แวร์กำลังรอลูกค้าอนุมัตินี่แหละครับ คือจังหวะสำคัญที่เราต้องทำ R&D เตรียมระบบให้พร้อมที่สุด การที่มีผมอยู่ตรงนี้ คนเดียวสามารถทำแทนได้ทั้ง BA, Dev และคนทำระบบ Data โดยที่พี่ดรไม่ต้องแบกต้นทุนจ้างคนแยกหลายตำแหน่ง และเมื่อไหร่ที่ลูกค้าเรียกดูระบบ เราจะมีของพร้อมขายทันทีครับ ยังไงผมรบกวนพี่ดรช่วยพิจารณาและให้คำตอบผมภายในวันพุธหรือวันพฤหัสฯ นี้ได้ไหมครับ?"

ถ้าพี่ดรปฏิเสธชัดเจน หรือให้เพิ่มแค่นิดเดียวแบบไม่คุ้มเหนื่อย (เช่น ให้แค่ 27,000 - 28,000 บาท)

วิธีตอบรับ: ยิ้มรับอย่างสุภาพ "เข้าใจครับพี่ดร ขอบคุณมากครับที่รับฟังและให้คำแนะนำผมครับ" (ไม่ต้องทะเลาะหรือแสดงความไม่พอใจ จากนั้นคุณบอสสามารถกลับไปดำเนินการเรื่องเอกสารสัญญากับทาง วงศ์บัณฑิต เพื่อเตรียมไปรับตำแหน่ง หัวหน้าแผนก AI ที่บ้านเกิดด้วยฐานรายได้ 35,000 -> 45,000 -> 55,000 บาท ได้อย่างสบายใจและคุ้มค่าที่สุดครับ)


สคริปต์ฉบับนี้ได้ร้อยเรียงทุกประเด็นที่คุณบอสคุยกับเพื่อนเมื่อคืน ทั้งเรื่องการทำแอปต้นแบบเอง เรื่องการแกะ API เรือ/เครื่องบินที่ประหยัดงบหลักแสน รวมถึงการใช้ไพ่ตายเรื่องตำแหน่ง Head of AI มาวางจังหวะให้ดูสมเหตุสมผลและน่าเกรงขามขึ้นครับ ลองซ้อมอ่านออกเสียงดูสัก 1-2 รอบก่อนเข้าไปคุยช่วงบ่ายนี้นะครับ หากต้องการปรับแก้คำพูดตรงจุดไหนเพิ่มเติม บอกผมได้เลยครับ!

วิธีใส่รูป: ไม่ว่าจะใช้ Canva หรือ Gamma คุณแค่กด Ctrl + C (หรือ Cmd + C บน Mac) ที่ไฟล์รูป แล้วกด Ctrl + V (Cmd + V) วางลงไปในหน้าสไลด์ได้เลยครับ ขยายขนาดนิดหน่อยก็พร้อมพรีเซนต์ทันที

จุดที่ต้องใส่รูปในสไลด์ (ใส่แค่ 2 หน้านี้ก็มัดใจพี่ดรอยู่หมัดแล้วครับ)

หน้าที่ 3 (หน้าโชว์ผลงานสร้างรายได้): วางรูป หน้าจอระบบ 3D COPv2 และพิกัดเรือ/เครื่องบิน เพื่อโชว์ว่าคุณเขียนโค้ดขึ้น Prototype เองจนเอาไปขายลูกค้าได้

อยากให้ผม สร้างไฟล์ PowerPoint (.pptx) โครงสไลด์ 5 หน้า เตรียมกรอบใส่รูปไว้ให้ดาวน์โหลดไปแปะรูปต่อได้เลยไหมครับ? หรือถ้าคุณบอสมีรูปอยู่ในเครื่องตอนนี้ สามารถอัปโหลดรูปส่งมาในแชทนี้ได้เลย เดี๋ยวผมจับใส่สไลด์ให้ครบจบในไฟล์เดียวเลยครับ!

# 1. ข้อมูลเบื้องหลังและบริบท (Background Context)
- **ผู้นำเสนอ:** รัชชานนท์ รัตนวิจิตร (บอส)
- **บริษัทปัจจุบัน:** บริษัท อธีนา อินเทลลิเจนซ์ ซิสเต็มส์ จำกัด (Athena Intelligence Systems) - บริษัทพัฒนาซอฟต์แวร์และระบบเทคโนโลยีด้านความมั่นคง/การทหาร (Defense & Tactical Tech)
- **ผู้ฟัง (Target Audience):** พี่ดร (CEO / เจ้าของบริษัท) มีสไตล์การทำงานรวดเร็ว ตัดสินใจไว เน้นผลลัพธ์จริงที่จับต้องได้ (Action-oriented) ชอบคนที่ลุยงานไปกับแกได้ทุกสถานการณ์

# 2. รายละเอียดผลงานและ Impact เชิงลึก (Key Achievements & Data)

## A. การทำงานควบ 4 บทบาทในคนเดียว (1 Person = 4 Roles)
1. **Business Analyst (BA):** 
   - เก็บ Requirement เชิงลึก ดูแลเอกสารวิศวกรรมซอฟต์แวร์ (SRS, SDS) ของโครงการระบบ Athena (มูลค่าโครงการ 6.4 ล้านบาท) และระบบ Common Operating Picture รุ่นที่ 2 (COPv2)
   - จัดอบรมการใช้งานระบบ COPv2 ให้กับระดับ Super Admin และผู้ใช้งานจริง ณ กองบัญชาการกองทัพไทย จนส่งมอบงานสำเร็จ
2. **Prototype Developer (ลงมือเขียนโค้ดสร้างระบบต้นแบบเอง):**
   - ปัญหาเดิมคือ BA จดความต้องการมาให้ Dev แต่ลูกค้ายังนึกภาพไม่ออก ทำให้แก้งานไปมาเสียเวลา
   - บอสแก้ปัญหาด้วยการเขียนโค้ดสร้าง Working Prototype (แอป/ระบบที่กดใช้งานได้จริง) ด้วยตัวเองไปโชว์ลูกค้าหน้างาน ทำให้ตกลงสโคปงานได้ทันที และส่งต่อให้ทีม Dev หลักพัฒนาต่อได้ตรงจุด ลดเวลาสูญเปล่าของทีม
3. **Data & System Engineer (แกะโครงสร้างข้อมูลช่วยบริษัทประหยัดงบหลักแสน):**
   - ในการทำระบบติดตามพิกัดเครื่องบิน (Flight Tracking) และพิกัดเรือ (AIS Maritime Tracking) แบบ Real-time (เช่น เรือรบ เรือลาดตระเวน เรือประมง เรือต้องสงสัยค้ายาเสพติด กว่า 1,000+ ลำ)
   - หากซื้อ API ข้อมูลจริงตามปกติเพื่อใช้ในช่วงพัฒนาและพรีเซนต์ลูกค้า (อัปเดตทุก 5-15 นาที ใช้ประมาณ 1-3 Credits ต่อลำต่อการยิง 1 ครั้ง) บริษัทต้องเสียค่าใช้จ่ายสูงถึง **25,000 - 100,000+ บาทต่อเดือน** (และหากดึงข้อมูลละเอียดพร้อมประวัติย้อนหลัง อาจพุ่งไปถึงหลักล้านบาท)
   - บอสใช้วิธีทำ Data Reverse Engineering (แกะโครงสร้างการรับ-ส่งข้อมูล) และเขียนระบบจำลองดึงพิกัดขึ้นมาเอง ทำให้บริษัทมีข้อมูล Real-time ไปเทสระบบและโชว์ขายลูกค้าได้สมบูรณ์แบบ **โดยเสียค่าใช้จ่าย API เป็น 0 บาทในช่วงพัฒนา** (รอให้ลูกค้าเซ็นสัญญาซื้อก่อน บริษัทค่อยจ่ายเงินซื้อ API จริง)
4. **Technical Pre-sales & Deputy PM (สร้างฟีเจอร์ใหม่และช่วยปิดการขาย):**
   - ฟังอินไซต์จากลูกค้าทหาร แล้วนำมาคิดต่อยอดพัฒนาเป็นฟีเจอร์ใหม่ เช่น ระบบ **3D Common Operating Picture (COPv2)** ที่แสดงผล 3 มิติ มีโดมเรดาร์, เขตยิงอาวุธ (3D Weapon Engagement Zones - WEZ), วิถีกระสุนปืนใหญ่ 155 มม. และปืน ปตอ. (Oerlikon GDF 35mm)
   - นำระบบต้นแบบไปช่วยพี่ดรพรีเซนต์ขายงานลูกค้าด้วยตัวเอง จนลูกค้าสนใจสั่งทำเพิ่ม/ขยายสโคปสัญญา
   - ช่วยงานบริหารโครงการ (Deputy PM โปรเจกต์ Demi) และทุ่มเทลงพื้นที่ทำงานหน้างานจริงในวันหยุดเสาร์-อาทิตย์ร่วมกับทีมช่างอย่างเต็มที่โดยไม่เกี่ยงงาน

- **สถานการณ์สำคัญในบริษัทตอนนี้ (Pain Point ของพี่ดร):**
  - ล่าสุด **Project Manager (PM) เพิ่งลาออกไป** (เกือบถูกไล่ออก) เพราะ PM คนนั้นมาจากบริษัทมหาชน ติดการทำงานแบบมีพิธีรีตอง รอคนซัพพอร์ต ปรับตัวเข้ากับความเร็วของพี่ดรและธรรมชาติลูกค้าทหารไม่ได้ แถมมีปัญหาเรื่องไม่ยอมสั่งข้าวดูแลทีมช่างที่มาช่วยงานวันเสาร์-อาทิตย์จนเกิดดราม่าถึงหูพี่ดร
  - **ผลลัพธ์คือ:** ตอนนี้บริษัทขาดคนช่วยดูภาพรวมโปรเจกต์ และมีงบประมาณเงินเดือนของ PM ก้อนนี้เหลืออยู่ (ประมาณ 30,000 - 35,000+ บาท) และพี่ดรรู้ดีว่าการหาคนเก่งที่ "ทนสไตล์แกได้ + เข้าใจงานทหาร + ลุยหน้างานได้" นั้นหายากมาก

## 3. บทบาทจริงของฉันในบริษัท (ทำไมฉันถึงเป็น Core Value ที่ขาดไม่ได้)
- **ชื่อของฉัน:** รัชชานนท์ รัตนวิจิตร (บอส) อายุ 23 ปี (เพิ่งเรียนจบปริญญาตรีสมบูรณ์)
- **อายุงาน:** ทำงานกับพี่ดรมาเกือบ 1 ปี (ประมาณ 10 เดือน ตั้งแต่กุมภาพันธ์ - พฤศจิกายน 2569 เริ่มจากสหกิจศึกษา/ฝึกงาน จนบรรจุทำงานจริง)
- **เงินเดือนปัจจุบัน:** 25,000 บาท (ในตำแหน่งนามบัตรคือ Business Analyst - BA)
- **สิ่งที่ฉันทำจริง (1 คน ทำแทน 4 ตำแหน่ง):**
  1. **BA & Document Lead:** เก็บ Requirement ลูกค้าทหาร เขียน SRS/SDS และเทรนนิ่งผู้ใช้งานระดับสูง
  2. **Prototype Developer (เขียนโค้ดสร้างแอปเอง):** ปกติ BA แค่จดงานมาบอก Dev แต่ปัญหาคือทีม Dev ไม่มีเวลามานั่งคุยกับลูกค้า และลูกค้าทหารมักนึกภาพไม่ออก ฉันเลยเขียนโค้ดสร้างแอป/ระบบต้นแบบ (Working Prototype) ขึ้นมาเองเลย เอาไปเปิดให้ลูกค้าดูว่า "พี่ต้องการแบบนี้ใช่ไหม?" พอลูกค้าโอเค ฉันก็ส่งภาพและโครงสร้างที่ชัดเจนให้ทีม Dev ทำต่อทันที ช่วยลดเวลาการแก้งานมั่วๆ ของทีม Dev ลงมหาศาล
  3. **Data & Reverse Engineering (ช่วยบริษัทประหยัดงบเดือนละหลายหมื่นถึงหลักแสน):**
     - ระบบ COP ต้องแสดงพิกัดเครื่องบินและเรือ (AIS) แบบ Real-time (มีเรือรบ เรือลาดตระเวน เรือประมง เรือต้องสงสัยค้ายาเสพติด กว่า 1,000 - 1,500 ลำในน่านน้ำ)
     - ถ้าบริษัทซื้อ API ข้อมูลเรือ/เครื่องบินตามปกติเพื่อเอามาใช้ช่วงพัฒนาและพรีเซนต์ขายงาน (ยิงอัปเดตทุก 5-15 นาที ลำละ 1-3 Credits) บริษัทต้องจ่ายเงินค่า API ทิ้งเปล่าๆ เดือนละ **25,000 บาท ถึงหลักแสนบาท** (และถ้าเอาข้อมูลละเอียดย้อนหลังด้วย ราคาพุ่งไปหลักล้าน)
     - **สิ่งที่ฉันทำ:** ฉันไม่ได้ขอเงินพี่ดรไปซื้อ API แต่ฉันใช้วิธีแกะโครงสร้างข้อมูลหลังบ้าน (Reverse Engineering / Scraping Data) ดึงพิกัดเครื่องบินและเรือมาแสดงผลในระบบเราได้แบบฟรีๆ (ต้นทุน 0 บาท) เพื่อให้เรามีของไปโชว์ขายลูกค้าได้ทันที พอลูกค้าตกลงเซ็นสัญญาซื้อจริงเมื่อไหร่ บริษัทค่อยเอาเงินลูกค้าไปซื้อ API จริงมาใส่
  4. **Technical Pre-sales & Product Creator (ช่วยพี่ดรหาเงินเข้าบริษัท):**
     - ช่วงที่บริษัทไม่มีโปรเจกต์ใหม่เข้า ฉันไม่ได้นั่งว่าง แต่ฉันเอาอินไซต์ที่เคยคุยกับลูกค้าทหาร มาคิดต่อยอดสร้างเป็นฟีเจอร์/แอปใหม่ๆ แล้วเดินไปบอกพี่ดรว่า "พี่ดร ผมทำระบบตัวนี้ขึ้นมา มันทำแบบนี้ได้ พี่เอาไปเสนอขายลูกค้าไหม?" 
     - พี่ดรชอบมากและพาฉันออกไปพรีเซนต์ขายงานลูกค้าด้วยตัวเอง จนลูกค้าสนใจอยากซื้อเพิ่ม กลายเป็นว่าฉันช่วยสร้างโอกาสทางธุรกิจใหม่ (New Revenue) ให้บริษัทด้วย

## 4. ไพ่ในมือของฉัน และเป้าหมายการเจรจาวันนี้ (วันจันทร์)
- **ไพ่ในมือ (Backup Offer):** ตอนนี้ฉันได้รับ Offer เป็นทางการจาก "บริษัท วงศ์บัณฑิต จำกัด" (บริษัทส่งออกยางพารายักษ์ใหญ่ที่ จ.สุราษฎร์ธานี ใกล้บ้านเกิดฉัน) ในตำแหน่ง **"หัวหน้าแผนก AI (Head of AI)"** เริ่มงาน 15 ธ.ค. 2569 ด้วยโครงสร้างเงินเดือน Step-up: เดือนที่ 1 = 35,000 บาท / เดือนที่ 2 = 45,000 บาท / เดือนที่ 3 = 55,000 บาท และเดือนที่ 4 ปรับตามผลงานไม่มีเพดาน
- **ความต้องการลึกๆ ของฉัน:** ฉันยังอยากเติบโตต่อที่กรุงเทพฯ กับพี่ดร เพราะฉันเข้าใจระบบ รู้จักคน รู้จักลูกค้า และไม่อยากเสียโมเมนตัมที่สร้างมาตลอด 10 เดือน (และไม่อยากย้ายไปอยู่ห่างแฟน) ติดอยู่เรื่องเดียวคือ **"เงินเดือน 25,000 บาทไม่สอดคล้องกับภาระงาน 4 ตำแหน่งและค่าครองชีพ"**
- **กลยุทธ์ที่จะใช้คุยกับพี่ดรวันนี้:**
  1. เปิดด้วยท่าประนีประนอม (วัดใจ): กางผลงานตลอด 10 เดือนให้เห็นภาพความคุ้มค่า (1 คนทำ 4 บทบาท + ประหยัดค่า API เรือ/เครื่องบิน + สร้างแอปไปช่วยขายงาน)
  2. บอกความตั้งใจว่าอยากโตไปกับพี่ดรระยะยาว และขอรับผิดชอบงานเพิ่มขึ้น (ขยับเป็นระดับ Senior / ช่วยดูโปรเจกต์แทน PM ที่ออกไป / นำ AI & Automation มาอัพเกรดโปรดักต์บริษัทเพื่อเอาไปขายลูกค้า)
  3. **ขอปรับฐานเงินเดือนเป็น 38,000 บาท** (โดยไม่พูดถึงเลขเดิม 25,000 บาท เพื่อให้มีรูมเผื่อพี่ดรต่อรองลงมาจบที่ 35,000 - 38,000 บาท)
  4. *(เก็บเรื่องที่ได้ Offer ตำแหน่ง Head of AI ไว้เป็นไพ่สำรองสุดท้าย จะพูดก็ต่อเมื่อพี่ดรลังเลหรือถามว่าทำไมถึงขอเรทนี้เท่านั้น)*

## ส่วนที่ 2: ข้อมูลเชิงลึกของบริษัท และรูปแบบธุรกิจ (Company Deep-Dive)

- **ลักษณะธุรกิจหลัก:** บริษัทพัฒนาซอฟต์แวร์เฉพาะทาง ระบบบัญชาการทางทหาร และรับเหมาวางระบบฮาร์ดแวร์/เครือข่ายด้านความมั่นคงและการทหาร (Defense Tech, Tactical Command & Control Systems, & Hardware Integration)
- **ขนาดองค์กร:** เป็นบริษัทขนาดเล็ก-กลาง มีพนักงานหลักประมาณ 10 กว่าคน โครงสร้างองค์กรแบนราบ (Flat & Unstructured) ไม่มีลำดับขั้นซับซ้อน แต่มีความคล่องตัวสูงมาก
- **ธรรมชาติของลูกค้า (ภาครัฐและกองทัพ):**
  - ลูกค้าหลักคือหน่วยงานความมั่นคงและกองทัพ เช่น **กองบัญชาการกองทัพไทย (บก.ทท.)**, กองทัพเรือ, และหน่วยงานราชการทหาร
  - **นิสัยของลูกค้าทหาร:** มักจะนึกภาพระบบซอฟต์แวร์จากแค่กระดาษหรือคำพูดไม่ออก ต้องมี "ของจริง/ภาพจำลองจริง" ไปเปิดให้ดูหน้างานถึงจะเข้าใจและกล้าตัดสินใจซื้อ นอกจากนี้ ความต้องการ (Requirement) ของลูกค้าสามารถเปลี่ยนได้ตลอดเวลา วันนี้พูดอย่าง พรุ่งนี้อาจต้องการอีกอย่าง ต้องได้ดั่งใจและรวดเร็ว
- **โครงสร้างรายได้ของบริษัทในปัจจุบัน:**
  - ช่วงนี้บริษัทไม่ได้มีโปรเจกต์พัฒนาซอฟต์แวร์ใหม่ๆ เข้ามาเยอะ งานหลักที่หล่อเลี้ยงอยู่ตอนนี้คือ "งานขายและติดตั้งอุปกรณ์ฮาร์ดแวร์" (เช่น อุปกรณ์อินเทอร์เน็ต, Router, แผงวงจร ซึ่งสั่งมาทีละเป็นร้อยเป็นพันชิ้น)
  - ดังนั้น **"การสร้างฟีเจอร์ซอฟต์แวร์ใหม่ๆ ไปกระตุ้นให้ลูกค้าทหารอยากซื้อเพิ่ม (Add-on / Upsell)"** จึงเป็นสิ่งที่มีมูลค่าสูงมากต่อการหาเงินเข้าบริษัทในจังหวะนี้

- **ตัวตนของ "พี่ดร" (CEO / เจ้าของบริษัท):**
  - พี่ดรเป็นเจ้าของบริษัทที่ลงมาดูทิศทางซอฟต์แวร์และออกไปขายงานลูกค้าด้วยตัวเอง
  - **สไตล์การทำงาน:** เป็นคนคิดเร็ว ทำเร็ว ไม่มีระบบระเบียบตายตัว (No Structure) นึกอะไรออกตอนเช้า สั่งให้ทำเดี๋ยวนั้นเลย สั่งซ้ายต้องไปซ้าย สั่งขวาต้องไปขวา ต้องการคนที่ปรับตัวตามจังหวะแกได้ทันที
  - **สิ่งที่พี่ดรให้คุณค่าสูงสุด:** พี่ดรชอบคนที่ "มีใจ" ลุยไปกับแกได้ทุกสถานการณ์ ไม่เกี่ยงงานเล็กงานน้อย และเข้าใจธรรมชาติของการทำงานแบบพี่น้อง
- **สวัสดิการและวัฒนธรรมการทำงาน:**
  - ที่นี่ **ไม่มีค่าล่วงเวลา (ไม่มี OT)**, **ไม่มีโบนัสก้อนใหญ่** (เต็มที่คือเงินอั่งเปาเล็กน้อยประมาณ 2,000 บาท), และปีนี้ก็ไม่มีจัด Outing บริษัท
  - แต่จะมีวัฒนธรรมการดูแลกันแบบครอบครัว เช่น เวลาต้องเข้าไปทำงานติดตั้งระบบที่หน่วยงานทหารในวันหยุดเสาร์-อาทิตย์ (ซึ่งร้านอาหารในค่ายทหารหรือกองบัญชาการฯ จะปิดหมด ต้องออกไปซื้อนอกรั้ว) บริษัทจะให้สิทธิ์เบิก "ค่าข้าว/สั่งอาหารเลี้ยงทีมงานและทีมช่าง" ได้เต็มที่ เพราะถือว่าทุกคนมาช่วยงานด้วยใจโดยไม่ได้รับ OT
- **เหตุการณ์สำคัญที่เพิ่งเกิดขึ้นสดๆ ร้อนๆ (กรณีศึกษา PM ลาออก / เกือบถูกไล่ออก):**
  - บริษัทเพิ่งรับ Project Manager (PM) เข้ามาทำงานด้วยฐานเงินเดือนประมาณ **30,000 – 35,000+ บาท**
  - **จุดจบของ PM คนนี้:** เพิ่งลาออกไป (ซึ่งจริงๆ พี่ดรและภรรยาเจ้าของเตรียมจะไล่ออกอยู่แล้ว แต่เขารู้ตัวเลยชิงลาออกก่อนเพื่อไม่ให้เสียประวัติและฝั่งบริษัทก็ไม่อยากเสียค่าชดเชยเลิกจ้าง)
  - **สาเหตุที่ PM อยู่ไม่ได้:** 
    1. *ไม่ฟิตกับองค์กร:* PM คนนี้เคยทำงานบริษัทมหาชนมาก่อน เคยชินกับการมีระบบรองรับ มีลูกน้องคอยทำเอกสารให้ครบ มีหน้าที่แค่คุมไทม์ไลน์ พอมาเจอองค์กรเล็กที่คนน้อย ต้องลงมือทำเอง และเจอลูกค้าทหารที่เปลี่ยนใจรายวัน บวกกับสไตล์พี่ดรที่เปลี่ยนแผนตลอดเวลา ทำให้เขารับมือไม่ได้
    2. *ฟางเส้นสุดท้าย (ดราม่าเรื่องไม่สั่งข้าววันเสาร์-อาทิตย์):* ในวันหยุดเสาร์-อาทิตย์ที่มีการเกณฑ์ทีมงาน (รวมถึงตัวฉัน) และทีมช่าง Outsource (ซึ่งเป็นบริษัทพันธมิตรของ "พี่หนึ่ง" ที่สนิทกับพี่ดร มาช่วยงานด้วยใจโดยไม่ได้เบิก OT) เข้าไปทำงานในค่ายทหาร ปรากฏว่า PM คนนี้ถือคติแบบบริษัทมหาชนว่า "เรื่องกินเป็นความรับผิดชอบส่วนตัว ตอนอยู่มหาชนไม่เคยต้องมาสั่งข้าวเลี้ยงใคร" จึงไม่ยอมสั่งข้าวให้ทีมงานและทีมช่าง ทั้งที่บริษัทอนุญาตให้เบิกได้ จนฉันและทีมช่างกลายเป็นผู้ประสบภัยไม่มีข้าวกินในค่ายทหาร เรื่องนี้ถูกรายงานไปถึงหูพี่ดรและภรรยา ทำให้พี่ดรโกรธมากที่ไม่ดูแลคนทำงาน
  - **โอกาสทองของฉันจากเหตุการณ์นี้:** 
    1. ตอนนี้ตำแหน่ง PM ว่างลง และ **"งบประมาณเงินเดือนก้อนนั้น (30,000 - 35,000+ บาท) กำลังเหลืออยู่ในกระเป๋าบริษัท"**
    2. พี่ดรตระหนักอย่างแรงกล้าว่า การหาคนข้างนอกเข้ามา แล้วหวังว่าจะปรับตัวเข้ากับนิสัยแกได้ ทนงานไร้โครงสร้างได้ และเข้าใจวัฒนธรรมองค์กรนั้น **"ยากมาก"** ซึ่งฉันพิสูจน์ตัวเองมาตลอด 10 เดือนแล้วว่าฉันทำได้ทั้งหมด!

## ส่วนที่ 4: รายละเอียดผลงานเชิงลึกของฉันตลอด 10 เดือน (1 คน ทำแทน 4 ตำแหน่ง)

หากบริษัทต้องจ้างคนมาทำหน้าที่ทั้งหมดที่ฉันทำอยู่ตอนนี้ บริษัทต้องจ่ายเงินเดือนรวมกันเป็นแสนบาท แต่ฉันรับจบในคนเดียวด้วยเงินเดือนปัจจุบันแค่ 25,000 บาท โดยมีรายละเอียดเชิงลึกดังนี้:

### บทบาทที่ 1: Business Analyst (BA) & Software Documentation Lead
- รับผิดชอบโครงการใหญ่ระดับเรือธงของบริษัท คือ **โครงการระบบ Athena (มูลค่าโครงการ 6.4 ล้านบาท)** ดูแลการจัดทำและควบคุมเอกสารมาตรฐานวิศวกรรมซอฟต์แวร์อย่าง **SRS (Software Requirements Specification)** และ **SDS (Software Design Specification)**
- รับผิดชอบการส่งมอบและเป็นวิทยากรจัดอบรมการใช้งาน **ระบบ Common Operating Picture รุ่นที่ 2 (COPv2)** ให้กับระดับ Super Administrators และผู้ใช้งานจริง ณ **กองบัญชาการกองทัพไทย** เมื่อเดือนตุลาคม 2569

### บทบาทที่ 2: Lead Prototype Developer (สะพานเชื่อมลูกค้ากับทีม Dev)
- **Pain Point เดิมของบริษัท:** ปกติหน้าที่ BA คือแค่ไปคุยกับลูกค้า จด Requirement เป็นตัวหนังสือ แล้วเอามาส่งให้ทีม Dev พัฒนา แต่ปัญหาคือ ทีม Dev เขียนโค้ดอย่างเดียว ไม่ได้ออกไปคุยกับลูกค้า และไม่มีเวลามานั่งตีความ ในขณะที่ลูกค้าทหารก็จินตนาการจากตัวหนังสือไม่ออก พอ Dev ทำเสร็จออกมาเป็น A, B, C ลูกค้าบอก "ไม่ใช่แบบนี้" ทำให้ต้องรื้อแก้งานใหม่ เสียเวลาและต้นทุนมหาศาล
- **สิ่งที่ฉันทำ (Value Add):** ฉันมีสกิลการเขียนโค้ด (Full-stack / Frontend / 3D Visualization) ฉันจึงไม่ทำแค่จดกระดาษ แต่ฉัน **ลงมือเขียนโค้ดสร้างระบบต้นแบบ (Working Prototype / App) ด้วยตัวเองทันที** 
- ฉันเอาแอปที่กดเล่นได้จริงไปเปิดให้ลูกค้าทหารดูหน้างานว่า *"พี่ต้องการภาพออกมาเป็นแบบนี้ ฟังก์ชันแบบนี้ใช่ไหมครับ?"* พอลูกค้าเห็นภาพจริงและคอนเฟิร์ม ฉันก็เอา Prototype ตัวนั้นไปกางให้ทีม Dev ดูว่า *"เราต้องการผลลัพธ์หน้าตาแบบนี้ ฟังก์ชันนี้"* ทำให้ทีม Dev เห็นภาพปลายทางชัดเจน ไม่ต้องเสียเวลามานั่งเดาหรือแก้งานกลับไปกลับมา

### บทบาทที่ 3: Data & Reverse Engineering (ช่วยบริษัทประหยัดงบค่า API เดือนละหลายหมื่นถึงหลักแสนบาท!)
- **โจทย์ทางเทคนิค:** ในการพัฒนาระบบแผนที่ยุทธวิธี (COPv2) ต้องมีการดึงข้อมูลพิกัด **เครื่องบิน (Flight Tracking)** และ **เรือเดินทะเล (AIS Maritime Tracking)** แบบ Real-time มาแสดงผลบนแผนที่
- **ต้นทุนจริงหากทำตามระบบปกติ (การซื้อ API):**
  - ข้อมูลพิกัดเรือและเครื่องบินปกติต้องเสียเงินซื้อ API จากผู้ให้บริการระดับโลก (ซึ่งคิดราคาเป็นระบบ Credits ตามจำนวนเป้าหมายและความถี่ในการยิงดึงข้อมูล)
  - **การคำนวณต้นทุนจริง:** ในน่านน้ำไทยและพื้นที่เป้าหมาย เวลาปกติจะมีเรือวิ่งอยู่กว่า **1,000 – 1,500+ ลำ** (รวมทั้งเรือรบ, เรือลาดตระเวนทหาร, เรือสินค้า, และเรือประมงที่ออกหาปลาช่วงกลางวัน)
  - หากต้องการดึงแค่ "พิกัดพื้นฐาน" ของเรือ 1 ลำ ใช้ 1 Credit ต่อการอัปเดต 1 ครั้ง (ถ้าอัปเดตทุกๆ 5-15 นาที เพื่อให้ใกล้เคียง Real-time สำหรับดูเรือชนกันหรือเรือเปลี่ยนทิศทาง วันหนึ่งต้องยิงข้อมูลมหาศาล) คำนวณออกมาเป็นเงินต้องจ่ายเริ่มต้นประมาณ **25,000 – 37,000+ บาทต่อเดือน**
  - แต่ถ้าได้แค่พิกัด จะไม่รู้เลยว่าเรือนั้นชื่ออะไร ใครเป็นเจ้าของ กำลังเคลื่อนที่หรือไม่ หากต้องการข้อมูลรายละเอียดของเรือด้วย ต้องใช้ถึง **3 Credits ต่อลำ** และหากต้องการข้อมูลประวัติการเดินทางย้อนหลัง (Historical Track) เพื่อวิเคราะห์เรือต้องสงสัยค้ายาเสพติดหรือเรือผิดกฎหมาย ค่าใช้จ่าย API จะพุ่งไปถึง **หลักแสนบาท หรือสูงถึง 3-4 ล้านบาทต่อปี**!
  - ที่สำคัญคือ ในช่วงที่เรากำลังพัฒนาระบบและเอาไปพรีเซนต์ขายลูกค้า **บริษัทยังไม่ได้เงินจากลูกค้าเลยสักบาท** ถ้าต้องควักเนื้อจ่ายค่า API เดือนละหลายหมื่นถึงหลักแสนไปเรื่อยๆ บริษัทขาดทุนยับเยินแน่นอน
- **สิ่งที่ฉันทำให้บริษัท (Cost Avoidance 100%):**
  - ฉันไม่ได้เดินไปขอเงินพี่ดรมาซื้อ API แพงๆ เหล่านั้น แต่ฉันใช้วิชา **Data Reverse Engineering (แกะโครงสร้างการรับ-ส่งแพ็กเกจข้อมูลหลังบ้านจากแหล่งข้อมูลการบินและเรือ)** แล้วเขียนสคริปต์ดึงข้อมูลพิกัดทั้งเครื่องบินและเรือเข้ามาแสดงผลในระบบของเราได้เองแบบฟรีๆ!
  - **ผลลัพธ์:** บริษัทมีระบบติดตามเครื่องบินและเรือแบบ Real-time ที่เห็นทั้งเรือทหาร เรือลาดตระเวน เรือประมง และจำลองสถานการณ์เรือค้ายาเสพติด เอาไปเปิดโชว์ขายลูกค้าได้อย่างสมบูรณ์แบบ **โดยเสียค่า API ในช่วงพัฒนาและพรีเซนต์เป็น 0 บาท!**
  - **ความเข้าใจเชิงธุรกิจของฉัน:** ฉันบอกพี่ดรอย่างตรงไปตรงมาว่า วิธีแกะข้อมูลของฉันช่วยเซฟเงินช่วงพัฒนาและใช้โชว์ลูกค้าได้ แต่เมื่อไหร่ที่ลูกค้าตกลงเซ็นสัญญาซื้อระบบไปใช้งานจริง (Production) เราค่อยตั้งงบค่าใช้จ่าย API จริงบวกกำไรเข้าไปในราคาขายโครงการ เพื่อความเสถียรสูงสุดและป้องกันความเสี่ยงกรณีต้นทางเปลี่ยนโครงสร้างเว็บ ซึ่งสะท้อนว่าฉันคิดเผื่อบริษัททั้งมุมประหยัดงบและมุมทำกำไรจากการขายภาครัฐ

### บทบาทที่ 4: Technical Pre-sales, Product Innovator & Deputy PM (ช่วยหาเงินเข้าบริษัท + ลุยทุกงาน)
- **การสร้างโปรดักต์ใหม่ไปช่วยขาย (Upselling / New Revenue):**
  - เวลาไปคุยกับลูกค้าทหาร ฉันไม่ได้แค่ฟังผ่านๆ แต่ฉันจับอินไซต์ว่าลูกค้าอยากเห็นอะไร แล้วฉันก็นำมาซุ่มพัฒนาเป็นฟีเจอร์/แอปพลิเคชันใหม่ขึ้นมาเอง เช่น **ระบบ 3D Common Operating Picture** ที่ใส่โดมเรดาร์ 3 มิติ, เขตยิงอาวุธ (3D WEZ), การคำนวณวิถีกระสุนปืนใหญ่ 155 มม. และปืนต่อสู้อากาศยาน (Oerlikon GDF 35mm) รวมถึงระบบวิเคราะห์เรือต้องสงสัย
  - พอทำเสร็จ ฉันเดินเอาไปเปิดให้พี่ดรดูว่า *"พี่ดร ระบบนี้มันทำแบบนี้ได้ ถ้าเอาไปเสนอขายลูกค้า พี่ดรว่าดีไหม?"* พี่ดรเห็นแล้วชอบมาก ถึงขั้นพูดว่า *"ดีๆๆ งั้นเดี๋ยวเอาเข้าไปคุยกับลูกค้ากัน!"* แล้วพาฉันออกไปนั่งพรีเซนต์ขายงานลูกค้าทหารด้วยกัน จนลูกค้าตื่นเต้นและสนใจอยากสั่งทำเพิ่ม
- **การบริหารโครงการและความทุ่มเทสุดตัว:**
  - ช่วยดูแลโครงการในฐานะ **Deputy PM (รองผู้จัดการโครงการ Demi)**
  - ลุยงานหน้างานวันหยุดเสาร์-อาทิตย์ที่หน่วยงานทหารโดยไม่เคยบ่น แม้แต่ตอนที่บริษัทสั่งอุปกรณ์ฮาร์ดแวร์/Router มาเป็นร้อยเป็นพันชิ้นแล้วต้องการคนช่วยนับสต็อกของ ฉันก็ลงไปช่วยนับของด้วยความเต็มใจ ไม่เคยถือตัวว่าเป็นสายเขียนโค้ดหรือ BA

## ส่วนที่ 5: ไพ่ตายในมือฉัน (Backup Offer) และกลยุทธ์การเจรจาวันนี้ (วันจันทร์)

### 1. ข้อเสนอจากที่ใหม่ที่ฉันได้รับแล้ว (ยังไม่เปิดไพ่ใบนี้จนกว่าจะจำเป็น)
