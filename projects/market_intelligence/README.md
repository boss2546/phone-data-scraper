# 📊 Market Intelligence & Deal Hunter

โมดูลวิเคราะห์เปรียบเทียบราคากลางสินค้าไอที และค้นหาข้อเสนอราคาคุ้มค่า (Cross-Platform Price Intelligence)

## ✨ ความสามารถหลัก (Features)
- **Cross-Source Price Comparison**: เปรียบเทียบราคาขายทางการของ Apple กับราคามือสองจาก CompAsia / Facebook
- **Deal Opportunity Hunter**: ตรวจสอบส่วนลด ความคุ้มค่า และการกระจายตัวของราคา
- **Executive CSV Reports**: ส่งออกรายงานสรุปสำหรับใช้วิเคราะห์ต่อยอดใน Excel / BI Tools

## 🚀 วิธีใช้งาน (Usage)
```bash
# รันวิเคราะห์ราคากลาง
python3 run.py
```
