# 👥 User Account Generator

เครื่องมือสร้างข้อมูลบัญชีผู้ใช้จำลอง (Synthetic User Personas) สำหรับใช้ทดสอบระบบ E-Commerce, GraphQL Authentication, Seed Database และ Load Testing

## ✨ ความสามารถหลัก (Features)
- **Synthetic Personas**: สร้างชื่อ-นามสกุลไทย, Username, Email, Phone number และ Secure Password
- **Role & Status Simulation**: กำหนดสถานะบัญชี (active) และสิทธิ์การใช้งาน (customer / admin)
- **Export Formats**: ส่งออกข้อมูลอัตโนมัติในรูปแบบ JSON และ CSV

## 🚀 วิธีใช้งาน (Usage)
```bash
# ใช้งานผ่านเมนูแบบ Interactive
python3 run.py

# กำหนดจำนวนบัญชีที่ต้องการสร้าง
python3 run.py 50
```
