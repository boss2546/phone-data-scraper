🧪 ห้องแล็บทดสอบ Universal Media Grabber (25 รูปแบบไฟล์จริง)

เลื่อนเมาส์ไปวางเหนือรูปภาพหรือวิดีโอชิ้นใดก็ได้ จะมีปุ่มดาวน์โหลดลอยขึ้นมาทันที พร้อมแปลงนามสกุลแปลก (.webp, .avif, .svg, .webm, .ogv, .mkv, .ts, .m3u8, blob:) เป็นไฟล์มาตรฐาน (.png / .jpg / .mp4) อัตโนมัติ!

⏳ กำลังเตรียมมีเดียทดสอบ...

🖼️ หมวดที่ 1: ทดสอบดึงและแปลงไฟล์ภาพ 15 รูปแบบ (แปลงเป็น .PNG และ .JPG มาตรฐาน)

1. ภาพ WebP สมัยใหม่ .webp ➔ .png/.jpg

ไฟล์ต้นฉบับ: sample_webp.webp

2. ภาพ AVIF บีบอัดสูง .avif ➔ .png/.jpg

ไฟล์ต้นฉบับ: sample_avif.avif

3. ภาพเวกเตอร์ SVG (<img>) .svg ➔ .png/.jpg

ไฟล์ต้นฉบับ: sample_svg.svg

4. กราฟิก Inline <svg> DOM SVG ➔ .png/.jpg

ต้นฉบับ: โค้ด <svg> ฝังในหน้าเว็บ

5. ภาพ GIF เคลื่อนไหว .gif ➔ .png/.jpg

ไฟล์ต้นฉบับ: sample_gif.gif

6. ภาพ Bitmap (.bmp) .bmp ➔ .png/.jpg

ไฟล์ต้นฉบับ: sample_bmp.bmp

7. ภาพ JFIF จากโซเชียล .jfif ➔ .png/.jpg

ไฟล์ต้นฉบับ: sample_jfif.jfif

8. ภาพ PNG มาตรฐาน .png ➔ .png/.jpg

ไฟล์ต้นฉบับ: sample_png.png

9. ภาพ JPG มาตรฐาน .jpg ➔ .png/.jpg

ไฟล์ต้นฉบับ: sample_jpg.jpg

10. แท็ก <picture> (AVIF/WebP) picture ➔ .png/.jpg

ต้นฉบับ: <picture> เลือก AVIF อัตโนมัติ

11. ภาพพื้นหลัง CSS Background CSS url(.webp) ➔ .png/.jpg

ต้นฉบับ: div style="background-image: url(...)"

12. กราฟิก HTML5 <canvas> Canvas ➔ .png/.jpg

ต้นฉบับ: วาดสดด้วย Canvas 2D Context

13. ภาพจากหน่วยความจำ (blob:) blob:webp ➔ .png/.jpg

ต้นฉบับ: blob:http://127.0.0.1:8765/...

14. ภาพแบบ Base64 Data URI data:image/webp ➔ .png/.jpg

ต้นฉบับ: data:image/webp;base64,...

15. ภาพที่มีเกราะใสบัง (Protected) Shielded .avif ➔ .png/.jpg

ต้นฉบับ: มี <div> ใสทับเหมือน IG/Shopee
